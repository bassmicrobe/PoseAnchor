# PoseAnchor 0.1.2 — ロゴ更新

提供された8点のSVGを`assets/branding/`に原形のまま収録しました。
濃色背景の通常アイコンをWindows用ICOに変換し、アプリ、Setup、Windowsアプリ一覧、
アンインストール用ショートカットで統一しています。READMEは背景の明暗に合わせて
横長ロゴを切り替え、ローカル表示用にも画像を同梱します。

ステータス画面は通常時にロゴを表示し、警告時はWindows標準の警告アイコンを維持します。
タイトルバー用アイコンはDPIに応じた大小2点だけを画面表示中に保持し、閉じると解放します。
タイマーや常駐処理、実行時依存は追加しません。
トラッキング処理のアルゴリズムに変更はありません。

## 検証

- 原本SVGとのバイト一致、PNG/ICOの再生成一致と透明背景を確認。
- ICOは16 / 20 / 24 / 32 / 40 / 48 / 64 / 128 / 256 pxを収録。
- Releaseビルドと自動テスト、Inno Setupによるインストーラー生成を確認。
- README用素材の欠落・古いICO/SVGの混入を防ぐパッケージ検査を追加。
- インストーラー関連184項目を確認。意図的に古いSVG/ICOを混入する試験でも出力を拒否。
- Release → Debug → Releaseの切替試験、安全な解除用の隔離fixture試験（6シナリオ・71項目）を確認。
- 配布先へのインストール、SteamVR実機動作、トラッキング改善効果は今回未検証。

0.1.1の試験結果や旧インストーラーのチェックサムは
[当時の配布準備記録](experimental-release-2026-10-15.md)に保存しています。
今回の版も実験版であり、実機ON/OFF比較での改善効果は未実証です。
